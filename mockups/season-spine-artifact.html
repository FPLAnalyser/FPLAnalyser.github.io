  3. 3With the plan open, flip Fixtures → xP to see every man’s projected points per week. The C on a cell is your armband; dim rows are that week’s bench. How the arrival marker got here

A — a green edge on filled chips: invisible on easy fixtures. B — one inverted cell in a filled grid: read well, but begged the question the grid above now answers — if dark-with-an-edge is the best-reading cell, why is only one cell drawn that way? C — the whole grid goes dark glass: every cell near-black with a faint gold edge, difficulty in the ink, and the handover straddles the seam: the leaver’s last cell takes a red right edge, the arrival the original green left edge, meeting at the boundary — the marker that drowned on filled chips works here, because the dark glass gives it nothing to drown in.

Real numbers. The fifteen is a plan built in the live builder, the fixtures and difficulty ratings are this season’s, and the projections and hard-fixture counts are what the app produces for that squad. Only the two played weeks are invented, since the season has not started — they are there to show the past-and-future split the line is built on. One approximation: per-player xP in the xP view is derived here from rating and fixture — the weekly totals on the bars are the app’s real projections, and the live build would read both from the same model.

Why the table never grows. The rows are your fifteen squad slots, not players. A transfer is one row changing hands: a green edge marks the week, and the names ride in a thin band above the row, each sitting over the stretch it owns — so Garner → Rice → Bruno → Saka is four labels on one band, and every fixture stays visible. A wildcard is many handovers in one column — the one above makes eight changes at GW9, so you can judge the size honestly: eight name bands cost about 90px, and the Names toggle folds them away when you want the grid back. Fifteen rows in August, fifteen in May.

The four data views. xP is approximated from rating and fixture, as before. Clean-sheet odds, xGI and Def Con start from each player’s real per-week xPts components in the ratings file, then bend with the fixture — and Def Con bends the other way, because defenders defend more in hard games. Venue is in the letterform everywhere: ABC at home, abc away.

What the expand would cost to build: nothing new. The bars are the gameweek strip that already exists. The rows are the Fixtures tab, already built, drawn on the strip’s columns instead of its own. The moves row is data the strip already computes. One CSS grid, one height animation.

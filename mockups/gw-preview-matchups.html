GW Preview — matchup edges, three ways

Every number below is the real GW1 computation: 92 attackers with 20+ shots on record, each scored against the club they actually face. Fit is how much of a player's own shot profile lands where that defence is weakest relative to the league, weighted by how much threat he has to redirect. The spread across a whole gameweek runs −9% to +15%, so this is a tie-breaker between two players you already fancy, not a reason to captain somebody. Any version of this needs to say so on the page.

◆ P2

One line per fixture, both sides of it

The Preview already walks the round fixture by fixture, so this sits inside that rhythm: for each game, the man each defence is least equipped to handle. Reads as match analysis rather than a leaderboard, and it never shows the same player twice. Costs more vertical space, and on a quiet fixture it has to be able to say "nothing to separate them" rather than manufacture an edge.

Where I'd go. P1 if this is meant to change what you buy: it is one section, it ranks the whole round, and it is the least new code because the Matchup Explorer already computes exactly this — the only change is looping over ten opponents instead of one. P3 if it is meant to make the Preview read better, because it costs nothing on the games where there is nothing to say. P2 is the handsomest and the one I'd resist: forcing a named man onto both sides of ten fixtures means inventing an edge nineteen times out of twenty, and the whole spread is fifteen points of percentage.

P1 + P3 together is the pair that works — the section for the reader who wants a shortlist, the line for the reader already scrolling the fixtures. And whichever ships, the caveat goes on the page: pre-season these are last season's shots, and a ±10% modifier is a tie-breaker, not a captain pick.

# Stadium photos (team-page banners)

Each team page opens on that club's stadium. Drop one landscape photo per club
here named exactly by its short code (uppercase, `.jpg`):

`ARS.jpg` `AVL.jpg` `BHA.jpg` `BOU.jpg` `BRE.jpg` `CHE.jpg` `COV.jpg` `CRY.jpg`
`EVE.jpg` `FUL.jpg` `HUL.jpg` `IPS.jpg` `LEE.jpg` `LIV.jpg` `MCI.jpg` `MUN.jpg`
`NEW.jpg` `NFO.jpg` `SUN.jpg` `TOT.jpg`

Until a photo is present, the banner shows a club-tinted floodlit-bowl gradient
fallback. Specs: landscape, ~1600px wide, ≤300 KB, licensed for use. A dark
scrim keeps the club name and stats readable over any image.

The banner is a wide letterbox using `object-fit: cover`, so a portrait or
square source is cropped hard down its centre. Crop to 16:9 around the part
worth keeping before dropping a file in here, rather than leaving it to CSS.
